# Telegram-бот для учёта инфраструктуры

Бот помогает фиксировать данные по кроссировке портов коммутаторов и
выгружать накопленные данные в виде Excel-файлов.

## Сценарий «Кроссовая»

1. `/start` — выбор раздела: **Принтеры** или **Кроссовая**.
2. **Кроссовая** → выбор этажа (1–11).
3. Выбор сегмента (**Сигма** / **Омега**).
4. Выбор коммутатора в стеке (1–5).
5. Выбор порта коммутатора (1–48).
6. Ввод номера СКС-порта (текстом).
7. Ввод комментария или пропуск кнопкой «Без комментария».

После заполнения запись добавляется в Excel-файл вида
`Кроссовая_Этаж_<N>.xlsx` (свой файл на каждый этаж) со столбцами:

| Дата | Сегмент | Коммутатор | Порт | Номер СКС | Комментарий |
|------|---------|------------|------|-----------|-------------|

Колонка «Порт» — это сквозной номер порта в стеке: для коммутатора 1
порт 48 = 48, для коммутатора 2 порт 48 = 96 и т.д.
(`(коммутатор - 1) * 48 + порт`).

## Раздел «Принтеры»

Пока заглушка — раздел в разработке.

## Выгрузка данных

Команда `/export` показывает список накопленных Excel-файлов кнопками,
по нажатию бот присылает выбранный файл документом.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите токен бота:

   ```bash
   cp .env.example .env
   ```

   ```
   BOT_TOKEN=ваш_токен_бота
   ```

3. Запустите бота:

   ```bash
   python bot.py
   ```

Файлы с данными сохраняются в каталог `data/` (создаётся автоматически).
